wardenhomelab security hub

No accounts yet. For safety there's no sign-up page: make the first admin on the machine warden runs on.

./warden-setup user add YOUR-NAME --role admin

It prints a one-time password. Sign in with it here and you'll be asked to pick your own.

Signed-in sessions end after a while idle. Lost your 2FA device? An admin can reset it, or run warden-setup user reset-2fa NAME.
